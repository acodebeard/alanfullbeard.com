# Resume Site Skeleton Design

## Goal

Build a clean, hardcoded PHP resume site for `alanfullbeard.com` that can run under local XAMPP/Apache, has a small routed structure, and imports the accessible demo form from `/home/alan/Documents/afullbeardsingle` as a non-functional showcase.

## Scope

The first version includes routes for `/`, `/portfolio`, `/plugins`, `/contact`, `/privacy`, and `/accessible-form`. The homepage contains a header, brief bio, portfolio summary, plugins summary, contact summary, and minimal footer. The header includes a download-resume button. The footer contains only copyright and a privacy policy link.

The site uses no CMS, no database, and no old-site application code. Content is hardcoded in PHP arrays and templates so Alan can edit it directly.

## Theme

Carry forward the verified old-site direction: blue-gray primary color, light gray panels, white header, Oxygen/Arial-style sans-serif text, compact page sections, accessible focus states, and restrained cards. The new code should not copy the old layout wholesale.

## Architecture

Use `public/index.php` as the front controller. Route definitions live in `app/content/pages.php`; rendering helpers live in `app/Site.php`; reusable markup lives under `app/views/`. Apache rewrites requests through `public/.htaccess`.

Security headers are generated by PHP helper functions and emitted by the front controller. The helper returns the header list so tests can verify it without relying on PHP's runtime header state.

## Accessible Form Import

Import the showcase form from the old site's `public_html/form-1.php`. Keep only its required assets: `css/forms.css`, Google/Apple sign-in images, `pineapple.webp`, and three status SVG icons. Adapt asset paths to `/assets/...` and render it inside the new layout under `/accessible-form`. The form remains demonstrative only: nothing is sent to a server, though draft restoration may use browser-local storage.

## Starter Bio Content

Use known information from the live site and local source: Alan Fullmer is Tucson-based, has over 14 years of website design/build/optimization experience, focuses on accessible, fast, understandable interfaces, has photography experience over 20 years, and works with practical interface repair, UX, performance, and plugins. The copy is starter text intended for Alan to edit.

## Testing

Use a small PHP CLI test runner before adding heavier tooling. Tests cover expected files, route resolution, rendered page landmarks/content, security header definitions, and accessible-form import markers. Add Composer scripts for `test` and `phpstan`.
