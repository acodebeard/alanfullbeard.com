Adds essential search and social metadata with simple controls in Settings > General.

== Description ==

Basic SEO Meta adds:

* An optional homepage SEO title.
* A default meta description.
* A Media Library control for the default social-sharing image.
* Open Graph metadata.
* X/Twitter card metadata.
* Featured-image support for individual posts and pages.
* JSON-LD for the website, site owner, current page, and social image.

The plugin leaves canonical URLs and normal page titles to WordPress core.

== Installation ==

1. Upload the `basic-seo-meta` folder to `/wp-content/plugins/`.
2. Activate Basic SEO Meta.
3. Open Settings > General and complete the Basic SEO fields.
