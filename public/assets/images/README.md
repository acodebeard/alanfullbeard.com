# Local Images

Current local files used by the accessible form showcase:

- `google-sign-in.webp`
- `apple-sign-in.webp`
- `pineapple.webp`
- `icons/check-solid-full.svg`
- `icons/check-double-solid-full.svg`
- `icons/xmark-solid-full.svg`

Keep production media on the deployment target or restore it locally as needed.
