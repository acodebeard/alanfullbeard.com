# Security Policy

## Reporting a Vulnerability

Please report security issues privately by emailing `alan@alanfullbeard.com`.

Do not open a public GitHub issue for sensitive reports. Include the affected URL or file, reproduction steps, impact, and any suggested fix if available.

## Scope

This repository is a hardcoded personal website with no CMS, database, or public account system. The accessible form showcase is non-functional and does not submit data to the server.
